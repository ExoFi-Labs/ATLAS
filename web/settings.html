Skip to settings

Runtime controls written into .env. Pick a chat model from Ollama (installed on this PC). RAG limits apply on the next question. Changing the LLM URL, TTS, or STT provider needs an ATLAS restart.

Language model

Default is Microsoft Phi-3 Mini (phi3:latest) via Ollama — a small model for laptops. Browse, pull, or inspect models on the Model page.

Retrieval (RAG)

Higher K searches more of Qdrant. Higher N sends more distinct emails into the prompt. Lower min score if answers miss relevant mail; raise it if noise creeps in.

Voice

Chat uses browser speech or Whisper in, then Google Chirp 3 HD (Kore) when TTS is google. Neural2 is the older general-purpose tier. Missing GCP credentials fall back to the browser voice.

Ingest and access

New emails inherit default roles. Dev roles decide what the local user can retrieve until SSO exists.
