This is the Qdrant console — the vector database ATLAS searches. Each indexed email becomes one or more points in a 384-dimension space. A question is embedded the same way; the nearest points become the answer’s sources. Add, open, browse, or delete records here.

Vector space

Each dot is a stored chunk. Nearby dots are similar in meaning, not in folder location. The ring is a query neighbourhood — RAG pulls the closest points, not the whole archive.
